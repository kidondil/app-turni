# Frontend LAPS Turni

Client Expo/React Native per web, iOS e Android.

```bash
npm ci
cp .env.example .env
npm run web
```

Impostare `EXPO_PUBLIC_BACKEND_URL` nel file `.env`, senza `/api` finale. Le istruzioni complete per backend, PIN e migrazione sono nel `README.md` principale.

Controlli disponibili:

```bash
npm run lint
npm run typecheck
npm run build:web
```
